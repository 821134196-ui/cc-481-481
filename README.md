# 支票簿领用与作废核验系统（虚构演示）

中国建设银行支票簿从申请、资格核验、双人出库、客户签收启用，到挂失止付、销户空白页交回、作废打孔与销毁批次的全流程核验系统。**全部网点、客户、账户、支票号码与凭证均为虚构数据**，仅用于流程演示。

纯 Python 标准库实现（SQLite + http.server），无任何第三方依赖。

## 一条本地启动命令

```bash
./run.sh            # 重建虚构样例数据并启动，默认 http://127.0.0.1:8000/
./run.sh 8012       # 指定端口
```

启动即自动准备四类样例：**客户拒领**（C-0088，5 张已作废待销毁）、**号码缺页**（库存 10000050 物理缺页，55 张申请取不到连续号段）、**挂失止付**（C-0003，已用 3 张、冻结 5 张）、**签收失败**（C-0077，签名不符待重签）。

进程内扫描任务每 20 秒扫描「待领」（自动完成签收）与「待销毁」（自动汇集销毁批次）；销毁的双人确认必须人工在页面完成，扫描不代确认。

## 页面台账

| 页面 | 内容 |
|---|---|
| 总览 `/` | 号码/支票簿统计、号码状态连续条带、作废水印与时间 |
| 申请审核 `/applications` | 资格适配器核验，通过即预留连续号段 |
| 号码段库存 `/inventory` | 全库存条带（红斜纹缺口）、可连续预留条带、缺页登记、提交申请 |
| 双人出库 `/disburse` | 经办/复核选择与实物数量核对；三列对齐的双人复核台账 |
| 签收启用 `/signoff` | 模拟签名适配器，成功才启用，失败可重签，拒领逐张作废 |
| 挂失止付 `/stop` | 冻结未使用号码、已用段不冻结、止付迟到单独标记 |
| 空白页交回 `/returns` | 销户清点，数量不符挂账、差异号码保持原状态 |
| 销毁台账 `/destroy` | 汇集批次、双人监销确认、销毁差异挂账、终态不可逆 |
| 事件台账 `/ledger` | 全部处理动作与扫描结果流水 |

## 关键规则

- **号码唯一**：`check_pages(branch_code, check_no)` 唯一约束，一个号码一行一状态，同一号码不可能同时属于两个有效状态。
- **连续号段预留**：只在不间断连续条带内预留，物理缺页会打断连续性；预留用 `BEGIN IMMEDIATE` + 状态条件更新，**两个柜员抢占同一支票簿时仅首笔成功**。
- **经办复核分离**：出库 `handler <> reviewer`（数据库 CHECK 约束 + 服务校验），销毁确认人同理必须不同账号。
- **签收才启用**：已出库的支票簿经签名适配器成功后方可启用；重复签收被拒绝。
- **止付阻断**：止付冻结未使用号码，已止付簿不可再签收/出库；号码已全部作废或销毁时记「止付迟到」。
- **交回数量不符**：只作废实际交回的号码，短缺号码保持原状态并挂账追查。
- **销毁不可逆**：批次双人确认后号码进入 `destroyed` 终态，不可重复确认、不可再作废、不可再启用；现场数量与应销不符则批次挂账不销毁。

## 数据存放

- SQLite 数据库：`data/bank.db`（号码状态机、全部台账）
- 虚构凭证：`data/vouchers/*.txt`（签收 / 作废打孔 / 销毁，含虚构业务讫章；查看仅限该目录，防路径穿越）

## 测试

```bash
python3 -m unittest tests.test_flow -v
```

13 个用例覆盖：号码唯一、经办复核分离、实物数量不符、双柜员抢占首笔成功、签收启用与重复签收、签收失败/拒领、止付阻断与止付迟到、交回数量不符、销毁双人确认与不可逆、销毁差异挂账。

## 目录结构

```
app/
  config.py    路径、配色、状态枚举
  database.py  SQLite schema、事务（BEGIN IMMEDIATE）
  adapters.py  模拟账户资格 / 签名适配器
  services.py  全流程状态机（申请→销毁）
  vouchers.py  本地虚构凭证文件
  scanner.py   进程内待领/待销毁扫描线程
  seed.py      虚构样例播种（拒领/缺页/止付/签收失败）
  views.py     纸张白/银行深蓝/印章红 视图、连续条带与水印标记
  web.py       路由与 HTTP 服务
  main.py      启动入口
run.sh         一条本地启动命令
tests/test_flow.py
```
