# 建设银行支票簿领用与作废核验系统（虚构演示）

> ⚠️ 本系统为**教学演示系统**，网点、客户、账户、凭证全部为虚构数据，
> 不连接任何真实银行系统，生成的“凭证”仅为本地文本文件。

零第三方依赖：仅使用 Python 3.11 标准库（`sqlite3` / `http.server` /
`threading` / `unittest`）。

## 一条命令启动

```bash
./run.sh                 # 默认 http://127.0.0.1:8000
PORT=8080 ./run.sh       # 自定义端口
```

启动时会**重置并准备拒领、缺页、止付等样例数据**，随后启动 Web 系统与
进程内扫描任务（每 30 秒扫描待领 / 待销毁记录，输出到控制台）。

其他入口：

```bash
python3 -m ccb_checkbook.seed      # 仅准备虚构演示数据
python3 -m ccb_checkbook.webapp    # 不重置已有数据直接启动
python3 -m unittest discover -s tests -v   # 全部 36 个测试
```

## 业务流程与状态机

```
申请(资格核验) → 审核 → 连续号码段预留 → 双人出库 → 客户签收 → 启用
                                   │            │
                                   └─驳回        ├─客户拒领─→ 止付冻结
                                                │
   启用 ──挂失止付──▶ 冻结未使用号码
        ──销户交回清点──▶ 逐张作废打孔(PART_VOID/FULLY_VOID)
                          └─作废号入销毁批次(号码即刻 DESTROYED)
                              └─双人确认封存 → 实物销毁(差异登记) → 不可逆
```

| 环节 | 规则 |
|---|---|
| 申请审核 | 模拟适配器核验账户资格（尾号 91 不通过）；经办与审核必须不同账号 |
| 号码段库存 | 按**连续号码段**预留；库存断号（缺页 51–59）和已占用号都会打断连续性；驳回号占位释放、永不复用 |
| 双人出库 | 经办 + 复核不同账号共同完成；`BEGIN IMMEDIATE` 行锁保证两个柜员抢占同一支票簿时**仅首笔成功** |
| 签收启用 | 模拟签名核对（尾号 92 不符，可人工核验放行）；签收成功才启用；**重复签收拒绝** |
| 挂失止付 | 仅冻结未使用号码（已使用的不受影响）；**止付阻断签收**；全部已用时报“止付迟到” |
| 空白页交回 | 销户清点应交/实交，逐张打孔作废；少交即“数量不符/缺页”，缺页维持冻结，找回后可补作废 |
| 销毁台账 | 作废号入批即置 `DESTROYED`（**不可再次启用**）；批次须双人确认封存、双人监销（须与封存人一致）；实销≠应收必须填差异说明；销毁不可逆 |

## 异常场景处理

- **号码缺页**：库存条带以斜纹“缺页”段显示；预留遇断号自动跳到下一连续段。
- **重复预留**：`check_numbers(branch_code, check_no)` 唯一约束兜底。
- **签收失败**：签样不符停留“待签收”，账册状态不变，审计日志记录失败。
- **客户拒领**：登记拒领原因、号码段冻结，生成拒领凭证。
- **止付迟到**：无未使用号码时拒绝止付。
- **交回数量不符**：交回单记 `MISMATCH` 与缺页数，账册转 `PART_VOID`。
- **销毁差异**：实销与应收不符且无差异说明时拒绝入账。

## 页面

- **总览台账**：KPI + 全部账册的印章式状态标记与时间。
- **申请审核**：资格核验流水、审核通过/驳回。
- **号码段库存**：起止号 + 缺口构成的**连续条带**（非逐张卡片），含图例。
- **双人出库**：待出库账册、实物数量、经办/复核双人选择。
- **签收启用**：每页三列对齐——经办信息 / 实物数量 / 签收结果；拒领带红色水印。
- **账册详情**：号码状态条带、止付、登记使用、交回打孔、缺页补作废、交回单与审计日志。
- **销毁台账**：批次归集、双人封存、销毁差异；作废/销毁状态同时显示文字、水印小标记和时间。
- **扫描记录**：进程内守护线程的待领 / 待销毁扫描结果。

配色：纸张白 `#fbf8f1`、银行深蓝 `#0b2a5b`、印章红 `#b3202e`。

## 目录结构

```
ccb_checkbook/
  db.py         SQLite 建表、状态常量、事务/审计
  service.py    业务状态机（全部业务规则）
  adapters.py   账户资格 / 签名模拟适配器
  vouchers.py   虚构签收/拒领/作废/交回/销毁凭证（本地文本）
  scanner.py    进程内定时扫描线程（待领、待销毁）
  seed.py       虚构演示数据（拒领/缺页/止付/待销毁样例）
  webapp.py     标准库 http.server Web 界面
tests/
  test_service.py  32 个领域规则测试
  test_webapp.py   4 个 HTTP 端到端测试
run.sh          一条命令：重置样例 + 启动
data/           运行后生成：checkbook.db、vouchers/*.txt（虚构）
```

## 测试覆盖

`python3 -m unittest discover -s tests -v`

- 号码唯一 / 连续段预留 / 缺页打断 / 驳回号不复用
- 经办复核分离（审核、出库、交回、销毁确认、监销人一致）
- 双人抢占同一支票簿仅首笔成功（真实双线程）
- 重复签收、签样失败、止付阻断签收、止付仅冻结未使用、止付迟到、拒领冻结
- 交回数量相符/不符、缺页补作废、已用号不交回、外来号/重复号拒绝
- 销毁号码终态不可逆、同号仅能进一个批次、封存后不可归集、销毁差异强制说明
- 凭证文件落盘、扫描线程输出
